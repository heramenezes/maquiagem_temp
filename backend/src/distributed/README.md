# Módulo de Distribuição e Paralelismo

Este módulo implementará as Seções 3.3 e 3.4 do projeto:
- Arquitetura de pipeline descentralizado entre nós independentes.
- Protocolo de comunicação Peer-to-Peer (P2P) para transferência de resultados intermediários entre estágios.
- Paralelismo a nível de dados em CPU (OpenMP) e aceleração em GPU (CUDA) para operações computacionalmente intensivas.
