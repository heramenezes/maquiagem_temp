# Módulo de Segmentação de Pele

Este módulo implementará as Seções 4.1 e 4.2 do projeto:
- Conversão da imagem do espaço de cor RGB para CIELAB.
- Segmentação de pele usando K-Means dinâmico (Islam et al., 2024).
- Recuperação de pixels de pele via Region Growing.
- Detecção e exclusão de regiões alteradas por condições pigmentares (acne, rosácea, vitiligo).
