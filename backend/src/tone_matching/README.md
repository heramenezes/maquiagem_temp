# Módulo de Estimativa de Tom e Recomendação de Base

Este módulo implementará a Seção 5 do projeto:
- Cálculo do Ângulo de Tipologia Individual (ITA):
  $$ITA = \left[\arctan\left(\frac{L^* - 50}{b^*}\right)\right] \cdot \frac{180}{\pi}$$
- Mapeamento para a Escala de Tons de Pele Monk (Monk Skin Tone Scale - 10 tons).
- Classificação e recomendação de produtos de maquiagem compatíveis usando KNN (K-Nearest Neighbors).
